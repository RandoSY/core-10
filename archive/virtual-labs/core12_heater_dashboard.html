Model Structure

Cth · dT/dt = Qin − Qloss
Qin = η · u · Pmax
Qloss = (T − Tamb)/Rth
τ = Rth · Cth

The thermal plant is an accountancy model: temperature rises only when net energy flux into storage is positive.

Export & measurement format

CSV and JSON exports include every simulation sample: time, plant temperature, sensor temperature, ambient temperature, setpoint, controller command, electrical heater power, thermal heater flux, heat loss, net flux, temperature rate, and control error.

Measured CSV may contain headers such as time_s,temp_c or time_min,temp_c. Imported measurements are overlaid on the temperature plot and interpolated to calculate residuals and RMSE.

Self-contained browser model. No server or external library is required. Numerical integration uses a bounded explicit time step and recomputes the complete result set whenever parameters change.
