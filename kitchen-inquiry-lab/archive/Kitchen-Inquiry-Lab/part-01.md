<td><strong>Scale Repeatability &amp; Tare Discipline</strong></td>

|                |                                                                                                                     |
|----------------|---------------------------------------------------------------------------------------------------------------------|
| **🎯 Purpose** | Establish that the eScale produces consistent, zero-referenced readings before any experiment depends on mass data. |

|                  |                                                                                             |
|------------------|---------------------------------------------------------------------------------------------|
| **🔧 Equipment** | eScale · Glass bowl or mug · Known-weight object (e.g., coin: US quarter = 5.670 g) · Water |

|              |                                                                                                                                                                     |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **📐 Model** | A well-calibrated scale reads the same object mass independently of history. Tare drift introduces systematic error in all downstream mass-difference measurements. |

|                 |                                                                                                                                                                                                                                                                           |
|-----------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **📋 Protocol** | 1\) Power on scale; confirm '0.0 g' display. 2) Place bowl; tare to zero. 3) Add ~100 mL water; record mass M1. 4) Remove bowl; confirm return to 0.0 g. 5) Re-tare; re-add same water; record M2. 6) Repeat 5×. 7) Weigh known object without taring; record 5 readings. |
