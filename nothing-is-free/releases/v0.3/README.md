This ZIP preserves the September 14, 2026 source edition containing the phone-first web app, simulation, teacher workflow, API/backend, Docker recipe and local launch scripts. Git blob SHA-1 was verified against the original file before publication.

**Important deployment warning:** the historical application includes a placeholder development secret in its configuration and disables secure cookies by default. It is an archived teaching prototype, **not a hardened public web service**. Before deploying anywhere reachable by other people, use a unique secret, HTTPS/secure cookies, disable demo seeding as appropriate and evaluate authentication and privacy controls. Do not store actual student records in a demo instance. The archived code was not rewritten to make these claims.
