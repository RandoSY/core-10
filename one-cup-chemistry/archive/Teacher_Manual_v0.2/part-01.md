**A spiral-bound teacher manual for chemistry, data acquisition, and AI

*Kitchen table → UNO/Multi-Function Shield → live data → AI critique →

| **DESIGN RULE** Keep the physical system simple. Increase the sophistication of the question. |

**Why One Cup Chemistry?**

A chemistry course should feel like one investigation getting deeper –
not twenty unrelated chapters.

**WHAT THE TEACHER GETS**

- 20 connected experimental guides, each with a driving question and
  theory.

- A common low-cost material system instead of a new apparatus every
  week.

- Kitchen Table and Instrumented modes for the same science.

- Reusable safety, data, AI, and assessment structure.

- A clear path from middle-school observation into
  high-school/intro-college ideas.

**WHAT MAKES IT DIFFERENT**

- Experience Before Equation: the phenomenon earns the mathematics.

- Need Before Technology: instrumentation arrives only when it solves a
  real problem.

- Same cup, deeper questions: continuity reduces cognitive overhead.

- AI is evaluated as a scientific reasoner, not used as decorative
  automation.

- Physical evidence stays authoritative.

**THE SALES PROPOSITION**

One inexpensive bench system can introduce measurement, thermochemistry,
solutions, stoichiometry, ions, conductivity, phase behavior,
crystallization, hydrates, diffraction, acid-base chemistry,
precipitation, electrochemistry, kinetics, spectroscopy, intermolecular
forces, and a bridge into biochemistry. The course is not claiming that
every chemical phenomenon literally occurs in one cup; it demonstrates
that one sufficiently examined physical system can provide a coherent
road through most of introductory chemistry.

| **THREE RULES** 1) Measure first. 2) Explain second. 3) Challenge the explanation third. |

Every guide ends with the question that creates the next guide. That
narrative continuity is the curriculum: students do not leave one topic
and enter another; they discover that the first system still has
unanswered questions.

**Core kit: start cheap, add only what the question demands**

| **Item**        | **Minimum specification**                          | **Why it earns a place**                                               |
|-----------------|----------------------------------------------------|------------------------------------------------------------------------|
| **Vessel**      | 250-400 mL clear polypropylene cup or small beaker | Universal reaction vessel; identical geometry matters for comparisons. |
| **Mass**        | 0.1 g digital balance                              | Mass, solution recipes, stoichiometry, evaporation.                    |
| **Volume**      | 100-250 mL cylinder + 10/20/50 mL syringes         | Large and small volumes.                                               |
| **Temperature** | Digital probe; DS18B20 recommended for logger      | Cooling, dissolution, phase change, kinetics.                          |
| **Time**        | Phone timer or UNO timer                           | Rates and reproducibility.                                             |
| **Transfer**    | Droppers/pipettes, stir rod, spoon                 | Small additions and mixing.                                            |
| **Optics**      | Visible LED + phototransistor/LDR                  | Beer-Lambert, turbidity, and monolayer boundary detection.             |
| **Electrical**  | Low-voltage conductivity module + multimeter       | Ions, galvanic cells, corrosion.                                       |
| **Acid-base**   | pH paper first; analog pH module later             | Qualitative then quantitative pH.                                      |
| **Safety**      | Goggles, gloves as required, labels, spill towels  | Non-negotiable laboratory habits.                                      |

**CORE CHEMICALS**

Tier A – household/low-hazard: distilled water, NaCl, sucrose, baking
soda, washing soda, vinegar/citric acid, Epsom salt, food coloring,
vegetable oil, dish detergent, 3% hydrogen peroxide, dry yeast, oleic
acid and isopropyl alcohol (for the OCC-17 monolayer experiment). Tier B
– signature salts: CaCl₂ deicer and a documented MgCl₂ hydrate product.
Tier C – teacher-controlled extensions: dilute prepared acids/bases,
copper sulfate or other specialty salts only where local rules and
disposal support them.

|                                                                                                                                                                                                                           |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **PURCHASING PRINCIPLE** Commercial deicers are valid teaching materials when the brand, ingredient statement, purity, and SDS are part of the experimental record. Product variability becomes a lesson, not a nuisance. |

**The digital bench: UNO + Multi-Function Shield**

Common MFS revisions provide a 4-digit display, three buttons, four
LEDs, buzzer, potentiometer, and a DS18B20/LM35 temperature-sensor
header. A widely used mapping is D4/D7/D8 for the display shift-register
interface, D3 buzzer, D10-D13 LEDs, A0 potentiometer, A1-A3 buttons, A4
temperature header, with D5/D6/D9 and A5 commonly available for add-ons.
Verify the exact shield revision before wiring because clones vary.

**The One Cup data spine**

**CUP → SENSOR → UNO + MFS → USB SERIAL → PC + AI**

*Physical data remain primary. AI is a reasoner over evidence, not a
substitute for observation.*

**SUGGESTED ASCII RECORD**

|                                                                                                                                               |
|-----------------------------------------------------------------------------------------------------------------------------------------------|
| **EXAMPLE** META,OCC-05,RUN=3,SALT=CaCl2,MASS_WATER_G=100.0,MASS_SALT_G=15.0 / T,0,22.84 / T,1000,24.11 / MARK,5230,SALT_ADDED / T,6000,31.72 |

The protocol should be deliberately boring: one line, comma-separated
fields, newline terminated. Students can read it. A spreadsheet can read
it. Python can read it. An AI can read it. Nothing important is hidden
behind a binary packet format.

**DATA INTEGRITY RULES**

- Never overwrite raw data; derived columns live in a separate analysis
  file.

- Every run carries experiment ID, sample ID, date/time, sensor ID,
  units, and controlled variables.

- Event markers are recorded in the same stream as measurements.

- Calibration information is versioned with the data.

- AI receives either raw data or an explicitly labeled processed
  dataset - never an unlabeled mixture.
