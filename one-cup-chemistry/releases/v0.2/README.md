# One Cup Chemistry — original complete v0.2 release

This is the exact **4,311,975-byte author-original ZIP** from the September 2026 curriculum project. It contains the branded teacher manual and student lab book as PDFs, their DOCX sources, a digital pack, an experimental Avogadro/soap-film guide, the original logo and release checksums.

**Original filename:** `One_Cup_Chemistry_Complete_Bundle_v0_2.zip`  
**SHA-256:** `047d7bd32a49b7bd78137736b270d699263c8c0ac859424398373988ce86525b`

To preserve the original bytes using the repository's verified binary-upload mechanism, the ZIP is stored losslessly in **five sequential binary pieces** (`archive-parts/*.part01` through `part05`). Each Git object was matched against the original part's Git blob hash during publication.

Run `python rebuild_one_cup_bundle.py` from this directory (or anywhere). It validates each part, concatenates them in sequence, compares the full SHA-256 and size, and checks the ZIP contents. It **will not overwrite** an existing ZIP.

Browsable original PDF editions are also at [original-editions](../../original-editions/). The separately indexed source-text teacher experiments are in [experiments](../../experiments/).

This is a **preservation release**, not a claim of independent bench/classroom validation. The historic OCC-07 soap-film filename in the bundle is not the same as the revised teacher-manual `OCC-17` assignment. Retain the original rather than silently renaming its interior contents.
